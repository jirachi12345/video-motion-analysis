# 儿童运动视频分析（Video Motion Analysis）

对儿童素质教育运动视频（滑板、篮球、足球、轮滑、跳绳等）进行结构化分析：使用 `ffmpeg` 提取关键帧，通过 AI 视觉模型识别运动项目、教学步骤与动作要领，输出包含**教学亮点、步骤拆解、不足改进与家长辅导建议**的完整分析报告。

## 功能特性

- 🎬 多策略关键帧提取（均匀采样 / 精确帧 / 补充帧），覆盖 <30 秒到数分钟的视频
- 🧠 AI 视觉批量分析：运动项目识别、动作姿态、画面文字 OCR、场地环境、安全评估
- 📋 结构化报告输出：教学步骤拆解表、教学亮点、不足与改进建议、家长分阶段辅导计划
- 👨‍👩‍👧 面向家长的实用输出：护具要求、练习时长控制、心理引导、环境选择建议

## 适用场景

- 分析儿童运动教学视频（滑板、篮球、足球、轮滑、跳绳、游泳、骑行等）
- 提取视频中的教学步骤和动作要领
- 诊断孩子运动动作中的问题并给出改进建议
- 为家长提供家庭辅导指导

## 工作流程

1. **获取视频信息**：用 `ffprobe` 获取时长、分辨率、帧率、编码等基本参数
2. **提取关键帧**：根据视频时长选择采样策略，用 `ffmpeg` 提取关键帧（缩放至 540 宽度以节省分析资源）
3. **AI 视觉分析**：调用 `image_analyze` 逐批（每批 6-9 张）分析帧图片，识别运动项目、动作要领、教学文字、场地与安全条件
4. **读取分析结果**：读取每帧分析生成的 Markdown 结果文件
5. **综合报告生成**：整合全部帧的分析结果，按报告模板输出完整结构化报告

### 帧提取策略

| 视频时长 | 采样策略 | 预计帧数 |
|----------|----------|----------|
| <30 秒 | 每 3 秒 1 帧 + 关键帧 | 10-15 帧 |
| 30-60 秒 | 每 5 秒 1 帧 + 补充帧 | 15-25 帧 |
| 1-3 分钟 | 每 10 秒 1 帧 + 关键帧 | 15-25 帧 |
| >3 分钟 | 每 15 秒 1 帧 + 场景切换帧 | 15-30 帧 |

## 报告结构

- 📋 **视频基本信息**：运动项目、教学对象、视频时长、教学形式
- 👧 **示范小朋友**：年龄估计、穿着装备描述
- 📝 **教学步骤拆解**：步骤 / 内容 / 教学目的 / 场地
- ✅ **教学亮点分析**：循序渐进设计、场地合理性、安全保障、心理建设
- ⚠️ **不足与改进建议**：动作规范性、安全隐患、教学节奏
- 💡 **给家长的辅导建议**：分阶段练习计划、安全护具、练习时长、心理引导、环境选择

## 分析重点维度

1. **运动项目识别**：项目特点与年龄适配性
2. **教学步骤提取**：步骤编号与名称（画面 OCR）、训练目的、递进关系、场地变化
3. **动作要领分析**：重心控制、手脚位置、身体姿态、平衡技巧、发力方式
4. **安全评估**：护具佩戴、场地安全性、动作风险等级、家长保护距离
5. **教学方法评价**：分步教学科学性、难度递进合理性、鼓励与心理引导、示范规范性

## 注意事项

- 帧提取目录统一使用工作目录下 `tmp/frames/`
- 分析用图片缩放至 540 宽度即可，节省传输和分析资源
- 个别帧可能因模型安全策略无法分析（尤其幼儿画面），可继续分析其他帧拼凑完整画面
- 分析完成后可清理 `tmp/frames/` 临时文件
- 报告语言与用户沟通语言保持一致，默认中文
